# Supplier messages (send in English via AliExpress chat)

## 1. First contact + Hebrew test (send to 3 suppliers)

```
Hello,

I'm opening an online store in Israel selling personalized name necklaces,
and I'm looking for a long-term supplier. I expect 20–50 orders/month to start.

Before ordering a sample, a few questions:
1. Can you engrave HEBREW text? Hebrew is written right-to-left. Letters must NOT be reversed.
   I will always send the names as text AND as an image you can copy.
2. What is the material and plating? (stainless steel 316L? 925 silver? gold plating thickness?)
3. Is it waterproof / does it tarnish?
4. How many days to produce, and which shipping method to Israel? How many days to arrive?
5. Is tracking provided to Israel?
6. Can you ship without invoices, prices, or your logo in the package (blind dropshipping)?
7. What is the price for 1 name and for up to 4 names, including shipping to Israel?

I will order a sample first with the Hebrew names: נועה · איתי

Thank you!
```

## 2. Sample order note (paste in the order note field)

```
SAMPLE ORDER, HEBREW ENGRAVING.
Names (copy exactly, right-to-left): נועה · איתי
Please see the attached image for the correct letter shapes.
Please send a photo before shipping. Thank you!
```

> Make an image of the names: type them in big font (Google Docs or Canva), screenshot, attach.
> Do this for **every** real order too.

## 3. Regular order note template

```
Order #[your Shopify order number]
Names (Hebrew, right-to-left, copy exactly): [names]
Color: [gold / silver / rose gold]   Chain: [45 cm]
NO invoice or prices in the package, please.
Please send a photo of the engraving before shipping.
```

## 4. Engraving error

```
Hello,

Order #[XXX] arrived with the Hebrew engraved incorrectly:
- Expected: [names]  (image attached)
- Received: [describe: reversed letters / wrong letter / wrong font]  (photo attached)

Please remake and ship this order at no cost, and confirm how you will
check Hebrew orders in the future. I plan to keep sending you orders
and want to resolve this quickly.
```

## Scoring

Once samples arrive, score each supplier with the 100-point template in
`.claude/skills/dropshipping/suppliers.md`. **Hebrew accuracy is pass/fail.** Any reversed or wrong letter on
the sample means don't use that supplier.

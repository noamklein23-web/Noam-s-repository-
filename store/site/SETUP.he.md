# הפעלת האתר והשליחה האוטומטית לספק

**מה יש כאן:**
- `index.html`: האתר (דף אחד בעברית, עם טופס הזמנה והדמיה חיה של השמות)
- `thank-you.html`: הדף שהלקוח מגיע אליו אחרי התשלום
- `config.js`: **ההגדרות. זה הקובץ היחיד באתר שצריך לערוך**
- `../apps-script/Code.gs`: הקוד שרושם הזמנות ב-Google Sheet ושולח מיילים

**איך זה עובד:**
```
לקוח ממלא טופס ← ההזמנה נשמרת בגיליון ("ממתין לתשלום")
   ← עובר לעמוד התשלום של חברת הסליקה ← משלם
   ← חוזר ל-thank-you.html ← הסטטוס מתעדכן ל"שולם"
   ← מייל אוטומטי: לספק (עם העתק אליך) + אישור ללקוח
```
הספק מקבל הזמנה **רק אחרי תשלום**. הזמנה שלא שולמה נשארת "ממתין לתשלום" ולא נשלחת לאף אחד.

כל ההגדרה לוקחת בערך שעה. הכל בחינם, חוץ מעמלות הסליקה.

---

## שלב 1: הגיליון והסקריפט (15 דקות)

1. היכנס ל-[sheets.new](https://sheets.new) עם חשבון הגוגל שלך, וקרא לגיליון "הזמנות – שלנו".
2. בתפריט: **Extensions → Apps Script** (תוספים ← Apps Script).
3. מחק את מה שכתוב שם, והדבק את **כל** התוכן של `store/apps-script/Code.gs`.
4. ערוך את החלק `CONFIG` בראש הקובץ:
   - `OWNER_EMAIL`: המייל שלך
   - `SUPPLIER_EMAIL`: המייל של התכשיטן
   - `DELIVERY_TEXT` ו-`WHATSAPP`: אותם ערכים שתכתוב ב-`config.js`
5. לחץ 💾 **Save**.
6. בתפריט שליד כפתור Run, בחר **setup** ולחץ **Run**.
   - גוגל יבקש הרשאה. לחץ **Review permissions**, בחר את החשבון שלך, ואז **Advanced → Go to (unsafe)** → **Allow**.
   - זו אזהרה רגילה לסקריפט שכתבת בעצמך. ההרשאות הן לגיליון הזה ולשליחת מיילים מהחשבון שלך.
7. **בדיקה:** בחר **sendTestEmail** ולחץ **Run**. תקבל שני מיילים: איך הספק יראה הזמנה, ואיך הלקוח יראה אישור.

## שלב 2: פרסום הסקריפט (5 דקות)

1. לחץ **Deploy → New deployment**.
2. ליד "Select type" לחץ ⚙️ ובחר **Web app**.
3. **Execute as:** Me. **Who has access:** Anyone.
4. לחץ **Deploy**, והעתק את ה-**Web app URL** (מסתיים ב-`/exec`).

> ⚠️ אם תשנה את הקוד בעתיד: **Deploy → Manage deployments → ✏️ → Version: New version → Deploy**.
> אחרת האתר ימשיך להשתמש בגרסה הישנה.

## שלב 3: העלאת האתר לאינטרנט (10 דקות, בחינם)

1. פתח את `config.js` והדבק את הכתובת משלב 2 ב-`appsScriptUrl`.
2. מלא גם: `whatsapp`, `email`, `businessName`, `businessId`, `deliveryText`.
3. היכנס ל-[app.netlify.com/drop](https://app.netlify.com/drop), פתח חשבון חינמי, **וגרור את התיקייה `site`** לחלון.
4. תקבל כתובת כמו `https://random-name.netlify.app`. אפשר לשנות לשם יפה יותר ב-Site settings, ובהמשך לחבר דומיין משלך.

> כל פעם שתשנה קובץ באתר, גרור את התיקייה שוב (Deploys → drag and drop).

## שלב 4: לינקים לתשלום (20 דקות)

אצל חברת הסליקה (Allpay, Grow, Pelecard או אחרת):
1. צור **שני לינקים לתשלום / דפי תשלום**: אחד ב-**₪139** (שם אחד) ואחד ב-**₪169** (2–4 שמות).
2. בהגדרות של כל לינק, חפש **"כתובת חזרה לאחר תשלום מוצלח"** (success URL / return URL), והכנס:
   `https://הכתובת-שלך.netlify.app/thank-you.html`
3. הדבק את שני הלינקים ב-`config.js` בתוך `paymentLinks`, וגרור את התיקייה ל-Netlify שוב.

> אם המחירים משתנים, עדכן בשלושה מקומות: הלינקים בחברת הסליקה, `prices` ב-`config.js`, ו-`PRICES` ב-`Code.gs`.

## שלב 5: בדיקה אמיתית אחת

עשה הזמנה מלאה בעצמך. אם אפשר, צור לינק זמני של ₪1 להזמנה הזו.
בדוק ש:
- [ ] ההזמנה הופיעה בגיליון כ"ממתין לתשלום"
- [ ] אחרי התשלום חזרת לדף התודה, והסטטוס השתנה ל"שולם"
- [ ] המייל הגיע לספק (ולך כהעתק) וגם ללקוח

**כדי לבדוק בלי לשלוח לספק האמיתי:** שים זמנית את המייל שלך ב-`SUPPLIER_EMAIL`.

## שימוש יומיומי

- **הכל אוטומטי.** הספק מקבל מייל, חורט ושולח, ומשיב לך עם מספר מעקב.
- **מספר מעקב:** כשהספק משיב, העבר את המייל ללקוח. או שתסכם עם הספק שישלח את המעקב ישר ללקוח, כי כתובת המייל של הלקוח מופיעה בהזמנה.
- **בדיקה שבועית (5 דקות):** השווה את רשימת התשלומים במערכת הסליקה מול השורות "שולם" בגיליון.
  זה חשוב: הסטטוס "שולם" מתעדכן כשהלקוח מגיע לדף התודה, ולא ישירות מחברת הסליקה. לקוח מתוחכם יכול, תיאורטית, להגיע לדף התודה בלי לשלם. בכמויות קטנות הסיכון נמוך, אבל הבדיקה השבועית תתפוס את זה.
- **לקוח שילם אבל ההזמנה נשארה "ממתין לתשלום"** (למשל אם סגר את הדפדפן לפני דף התודה): שנה בגיליון את הסטטוס ל-**שולם**, והמייל לספק יישלח אוטומטית.
- **רוצה לבדוק כל הזמנה לפני שהיא יוצאת לספק?** ב-`Code.gs` שנה `AUTO_SEND_TO_SUPPLIER: false`. ההזמנות יגיעו רק אליך, ואתה תעביר אותן.
- **מגבלת מיילים:** חשבון גוגל רגיל שולח עד 100 מיילים ביום, שזה כ-50 הזמנות ביום. מספיק להתחלה.

- [ ] פרטי העסק (שם ומספר עוסק) בתחתית האתר
